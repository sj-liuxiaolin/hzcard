# 🧱 瓦工技术交底卡
> 适用对象：瓦工班组长 | 涵盖：地梁浇筑、墙体砌筑、墙地砖铺贴

---

## 一、地梁浇筑标准

### 施工流程
拆除原始墙体/吊顶/地面 → 整体放线 → 制模 → 预埋钢筋 → 浇筑 → 拆模

### 关键参数
| 项目 | 标准 |
|------|------|
| 竖向钢筋 | Φ8 |
| 横向钢筋 | Φ6 |
| 客房隔墙地梁厚度 | 200mm（以图纸为准） |
| 卫生间地梁厚度 | 100mm |
| 拆模（长度2-8m） | 强度≥75% |
| 拆模（长度＞8m） | 强度100% |
| 模板要求 | 木质专用模板，表面光滑 |

### 正确范例
√ 植筋胶使用到位
√ 模板支撑牢固、接缝严密
× 错误范例：无钢筋的地梁（严禁！）
× 错误范例：原始地砖未拆除就直接浇筑

### 地梁抬高情况
- 遇地暖或同层排水 → 地梁需适当抬高
- 厨房抬高区域 → 地梁适当抬高

## 二、墙体砌筑标准

### 过梁及构造柱
- 墙体长度超过5米：设置钢筋混凝土构造柱
- 墙体高度超过4米：设置钢筋混凝土圈梁
- 新老墙体搭接：钢丝网两边搭接＞150mm

### 砌筑要求
- 灰缝不低于10mm
- 灰缝饱满
- 墙体到顶后粉刷
- 墙体甩浆处理
- 禁止顶部不放置斜砖
- 禁止使用轻质板墙、空心砌块砖

### 正确范例
√ 灰缝饱满，不低于10mm
√ 拉结筋设置到位
√ 新老墙体搭接钢丝网

### 错误范例
× 灰缝不饱满 → 隔音测试仅19分贝（严重影响隔音！）
× 存在多处漏光漏缝 → 客房隔音严重受影响
× 顶部未放置斜砖
× 使用界面剂

## 三、墙地砖铺贴标准

### 墙面砖
1. 铺贴前拉线找平、找方
2. 瓷砖浸泡≥2小时，晾干后方可铺贴
3. 瓷砖缝隙均匀，宽度≥2mm
4. 墙面砖铺贴完成后，用橡皮锤轻轻敲实
5. 空鼓率：单块砖≤15%，整体≤5%

### 地面砖
1. 铺贴前基层清扫干净，洒水湿润
2. 地砖铺贴坡度正确，地漏为最低点
3. 卫生间地面砖铺贴完成后做保护
4. 过门石铺贴要高于卫生间地砖10-15mm（挡水作用）

| 检查项 | 标准 |
|--------|------|
| 表面平整度 | ≤2mm（2m靠尺） |
| 接缝高低差 | ≤0.5mm |
| 接缝宽度 | ±0.5mm |
| 空鼓率 | 单块≤15%，总数≤5% |

### 正确范例
√ 墙砖压地砖（卫生间墙面）
√ 地漏处做回字形切割
√ 过门石两端伸入门套

### 错误范例
× 墙地砖通缝（应错缝铺贴）
× 地面砖坡度不够导致积水
× 空鼓超标
