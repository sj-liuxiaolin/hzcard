# 🎨 油漆工技术交底卡
> 适用对象：油漆工班组长 | 涵盖：墙面涂料标准

---

## 一、墙面涂料施工标准

### 基层处理
1. 墙面基层必须干燥，含水率≤10%
2. 基层平整度检查：≥3mm需找平
3. 腻子批刮前，基层界面处理（墙固/界面剂）
4. 阴阳角弹线找直

### 腻子施工
| 工序 | 要求 |
|------|------|
| 第一遍腻子 | 横批，厚度≤2mm |
| 第二遍腻子 | 竖批，厚度≤1mm |
| 打磨 | 用240目以上砂纸，打磨平整 |
| 清理浮灰 | 打磨后必须清扫干净 |

### 涂料施工
| 工序 | 要求 |
|------|------|
| 底漆 | 1遍，均匀涂刷 |
| 第一遍面漆 | 表干后施工（间隔≥2h） |
| 第二遍面漆 | 第一遍实干后施工（间隔≥4h） |

### 特殊部位处理
- 吊顶石膏板接缝：嵌缝膏填缝+绷带/网格带
- 石膏板自攻螺丝头：防锈处理（防锈漆或水泥+801胶水）
- 阳角：放置护角条
- 开关插座周边：批灰平整

### 正确范例
√ 阴阳角顺直
√ 墙面平整光滑
√ 分色线清晰（踢脚线、门套位置）

### 错误范例
× 基层未干透就批腻子（导致起泡、脱落）
× 腻子一次批刮过厚（导致开裂）
× 未打磨就刷涂料
× 漏水处未处理就批灰

---

## 二、客房涂料特殊要求

1. 喷涂施工时对喷淋、烟感做好防护
2. 涂料施工环境温度≥5℃，湿度≤85%
3. 每遍涂料必须实干后方可施工下一遍
4. 不得在涂料中加水过量（影响遮盖力和耐久性）

---

## ⚠️ 验收关键点
1. ✔ 墙面平整度（≤2mm/2m靠尺）
2. ✔ 阴阳角方正
3. ✔ 无起皮、开裂现象
4. ✔ 涂刷均匀无流坠
5. ✔ 分色线平直
